# รูปของขาย Robux ด้วย GPT (Game Pass 5 + Developer Product 12 = 15 รูป)

แต่ละข้อมี prompt ครบในตัว: คัดลอกทั้งกล่องไปวางใน ChatGPT ได้เลย ไม่ต้องเติมอะไร
รูปเดียวใช้เป็น **รูปของ pass / product ในเว็บ Roblox** และเกมจะดึงไปโชว์ใน **ร้าน Robux ในเกม** เอง

## วิธีใช้
1. เปิดแชทใหม่ใน ChatGPT แล้ว **แนบรูป `art/preview/cats_lineup.jpg`** (แมวจริงในเกมเรา) แล้วพิมพ์บรรทัดนี้ก่อน:
   `This is my own game's art. Draw every cat in exactly this smooth blocky style (no studs) for the next images.`
2. ทำข้อ 1 (x2 Speed) กับข้อ 14 (เรียกแมว Mythical) ก่อน ถ้าถูกใจ ทำข้อที่เหลือในแชทเดิม
   แล้วพิมพ์ต่อท้ายทุก prompt ว่า `Keep exactly the same art style, lighting and camera as the previous images.`
3. ได้รูปแล้ว ตั้งชื่อไฟล์ตามชื่อในวงเล็บของแต่ละข้อ (เช่น `Speed2x.png`) ใส่ที่ `art/source/gpt_items/` แล้วบอกผม
   ผมจะลบพื้นหลัง ย่อเป็น 512 x 512 แล้วส่งกลับให้อัปโหลด
4. ช่องคอก +20 มี 3 อัน (Slots1, Slots2, Slots3) ใช้ **รูปเดียวกัน** (`Slots.png`) ได้ จึงมี 15 รูป ไม่ใช่ 17

## กติกาที่เขียนไว้ในทุก prompt แล้ว
- **1024 x 1024** สี่เหลี่ยมจัตุรัส **พื้นหลังโปร่งใส** (ถ้าได้พื้นขาวก็ส่งมาได้ ผมลบให้)
- ของอยู่กลางภาพ ไม่ชิดขอบ เพราะ Roblox ตัดรูป game pass เป็นวงกลม
- **ไม่มีตัวหนังสือ** ยกเว้นคำที่ระบุไว้ในแต่ละข้อ (x2, x3, +20, VIP)
- ไม่มีไอคอน Robux ไม่มีโลโก้ ไม่เอ่ยชื่อเกมอื่น Lego หรือ Roblox

## เคล็ดลับ (พิมพ์ต่อในแชทเดิมเมื่อรูปเพี้ยน)
- ตัวเลขเพี้ยน: `Make the text exactly "x2" in chunky 3D blocky letters, nothing else written.`
- พื้นหลังไม่โปร่งใส: `Same image on a fully transparent background, PNG.`
- มีปุ่มกลม (studs) โผล่มา: `Remove every round stud: all surfaces are smooth and flat, like the picture I attached.`
- แมวไม่เหมือนในเกม: `Make the cat exactly like the cats in the picture I attached: cube head, triangle ears, small square eyes.`
- รกเกินไป: `Simpler: one main object, bigger, fewer small things around it.`
